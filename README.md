# hello-ios-build

Minimal SwiftUI app used to verify iOS builds on GitHub Actions macOS runners.

- Source: `HelloApp/` (two Swift files), project generated by XcodeGen from `project.yml`
- CI: `.github/workflows/build.yml` runs on `macos-latest`, builds for the iOS
  Simulator with signing disabled, and uploads the `.app` bundle as an artifact.

Trigger: push to `main` or manual `workflow_dispatch`.
